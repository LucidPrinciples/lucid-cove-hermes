# Skill — git on this overlay

Work in the clone of `LucidPrinciples/lucid-cove-hermes`.

## Ship (locked)

1. New branch off `main`
2. Commit (no hostnames, home paths, secrets)
3. `git push -u origin BRANCH`
4. Open a GitHub PR against `main`
5. Stop. Do not merge. Do not force-push.

## Do not

- Push to `main` except the initial public seed (already done)
- Put tokens in commit messages, remotes, or chat
- Treat this clone as a live deploy — merge, then the operator updates their install
