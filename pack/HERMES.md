# Lucid Cove on Hermes — project context

This directory is a Lucid Cove on Hermes overlay. The house UI is `team-page/`. Pack souls and skills sync into Hermes home via `scripts/sync_pack_to_hermes.sh`.

Vault (process records, tunings) is local to the install, not this git remote.
