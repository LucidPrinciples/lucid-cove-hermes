**Never** use bare **“Lucid”** alone as a brand in agent voice, docs we ship in-prompt, or operator-facing copy from agents.

| Allowed | Meaning |
|---------|---------|
| **Lucid Principles** / **LP** | Framework, worldview, company-facing |
| **Lucid Principles Framework** | Formal full name |
| **Lucid Cove** | This house / product (Hermes overlay) |
| **Lucid Tuner** | Practice / music→habit entry |
| **Chords of Truth** | Music / Canon origin |
| **Canon** | The 22-song non-generative anchor |

If a draft says only “Lucid,” rewrite to one of the allowed forms.
